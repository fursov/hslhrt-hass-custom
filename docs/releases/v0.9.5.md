# v0.9.5 — Release notes (draft)

This is a small **metadata-only** release of the Helsinki Regional Transport
(HSL HRT) custom integration for Home Assistant.

## What's changed since v0.9.4

- Added the recognized Home Assistant/Marketplace integration category
  `vehicles_transport.public_transport` to
  `custom_components/hslhrt/manifest.json` for improved discovery.
- Updated `CHANGELOG.md` to recognize the published v0.9.4 (October 27,
  2026) and v0.9.2 (October 26, 2026) releases.
- Prepared the project for a clearer GitHub repository description and a
  public integration catalog listing.

**No runtime changes.** The existing Digitransit API calls, realtime
arrival calculations, HFP MQTT GPS tracking, multi-stop vehicle marker
deduplication, entities, unique IDs and configuration remain unchanged.

## Compatibility

- Minimum Home Assistant Core: **2026.10.2** (from `hacs.json`).
- Existing stop configuration entries continue to work unchanged.
- No new dependencies or permissions, and no new Digitransit API key required.
- Version in `manifest.json` is `0.9.5`.

## Suggested GitHub repository description

> Home Assistant integration for HSL public transport: realtime departures,
> stop timetables and live vehicle tracking in Helsinki.

This is the repository **About** description, not part of the integration
manifest. The connected GitHub actions do not provide repository metadata
editing. The repository owner can set it via **GitHub → repository main page
→ About (gear icon) → Description → Save changes**.

Recommended additional GitHub topics, if desired: `hsl`,
`public-transport`, `helsinki`, `digitransit` (alongside the existing
`hacs`, `home-assistant`).

## Release checklist

1. Merge the v0.9.5 preparation PR after Ruff, smoke tests, HACS, Hassfest
   and Home Assistant integration CI succeed.
2. In the merged `main` commit, check `manifest.json` version `0.9.5`
   and the `vehicles_transport.public_transport` category.
3. Update the repository **About** description as above (optional; GitHub
   metadata is not modified by the release PR).
4. Tag that exact commit `v0.9.5`, create and publish the corresponding
   GitHub Release; use the notes above without this checklist and without
   “draft” in the title.
5. Check the new release is visible in HACS and that Home Assistant still
   discovers the integration normally.

**This preparation PR does not create or publish the release tag.**
